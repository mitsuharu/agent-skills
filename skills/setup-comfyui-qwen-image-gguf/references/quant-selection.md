# VRAMによる量子化の選び方

GGUF本体の量子化を決めるときに読む。ファイル名とサイズは固定せず、実行時にリポジトリのファイル一覧から確認する。

## 基本ルール

1. `nvidia-smi --query-gpu=memory.total,memory.used --format=csv` でVRAM総量を確認する。
2. リポジトリにある量子化ごとのファイルサイズを一覧にする。
3. **ファイルサイズがVRAM総量の約55%以下のもの**のうち、最も大きい（高画質な）量子化を選ぶ。残りは生成時の中間データ、VAE、ComfyUI自身の使用分に充てる。テキストエンコーダはComfyUIが必要に応じてRAMへ退避するため、この計算に含めない。
4. 同程度のサイズで迷う場合は `Q8_0` > `Q6_K` > `Q5_K_M` > `Q4_K_M` の順に画質を優先する。`Q3` 以下は他に選択肢がない場合だけ使う。

## 目安

Qwen-Image-2.1のQ8_0は約7.6GB。他の量子化のサイズはリポジトリで確認する。

| VRAM | 目安の量子化 |
| --- | --- |
| 16GB以上 | `Q8_0`（実績: RTX 5070 Ti 16GBで1024×1024を生成できた） |
| 12GB | `Q6_K` または `Q5_K_M` |
| 8GB | `Q4_K_M` |
| 8GB未満 | `Q3_K_M` 以下。解像度を下げることも案内する |

目安と基本ルールが食い違う場合は基本ルールを優先し、選んだ理由をユーザーに伝える。

## 注意点

- ブラウザやChatGPTなど他のアプリがVRAMを使っていると、選んだ量子化でも遅くなる。`nvidia-smi` で使用中のプロセスを確認し、必要なら閉じるよう案内する。
- ユーザーが速度や容量を優先したい場合は、1段軽い量子化を提案する。
